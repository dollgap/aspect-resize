# 비율 리사이즈

사진을 **자르지 않고** 스레드·인스타 규격(1:1, 4:5, 3:4, 16:9, 9:16)에 맞추고, 남는 위아래·양옆 공간을 흰색·검정·블러·대표색 배경으로 채워 주는 웹앱입니다. 여러 장을 한 번에 올려 ZIP으로 받을 수 있고, 홈 화면에 추가해 앱처럼 쓸 수 있습니다(PWA).

- 주소: https://dollgap.github.io/aspect-resize/

## 기능

- **비율 프리셋**: 1:1(정방형) · 4:5(인스타 피드) · 3:4(스레드 세로) · 16:9(가로) · 9:16(스토리·릴스) + 가로↔세로 뒤집기
- **안 잘리게 맞추기(Contain)**: 사진 전체가 비율 안에 들어갑니다. 여백 슬라이더 0~20%
- **여백 배경 4종**
  - 블러: 원본을 꽉 채워 확대하고 가우시안 블러 + 밝기 조절, 그림자·라운드 모서리 선택
  - 흰색 `#ffffff` / 검정 `#000000`
  - 자동색: 사진 테두리의 평균색을 뽑아 배경으로 사용, 직접 색을 고를 수도 있음
- **여러 장 일괄 처리**: 썸네일로 골라 가며 실시간 미리보기, EXIF 방향 자동 보정
- **저장**: 해상도 1440(짧은 변 기준, 기본) / 1080 / 원본 픽셀 유지, 형식 JPG / PNG
- **내보내기**: 장별 저장·공유, 전체 ZIP 저장(순수 JS ZIP, 외부 라이브러리 없음)

## 개인정보

사진은 서버로 전송되지 않습니다. 비율 조절과 배경 합성은 모두 이 기기의 브라우저 안에서만 이뤄지고, 외부 CDN·API·분석 도구를 쓰지 않습니다. 앱을 한 번 열면 서비스워커가 앱 셸만 캐시해 인터넷 없이도 동작합니다.

## 홈 화면에 추가

- Android(Chrome): 주소를 연 뒤 브라우저 메뉴 → **홈 화면에 추가**
- iPhone(Safari): 공유 버튼 → **홈 화면에 추가**
